🔧 连接你的 GitHub 仓库

聊天记录存进你自己的仓库，永久保存、换手机也在、不用服务器。
和卤味后台是同一套做法。

怎么拿（30 秒）：
1. 打开 github.com/settings/personal-access-tokens/new
2. Repository access 选 Only select repositories，只勾这个聊天仓库
3. Permissions → Contents 选 Read and write
4. 生成后复制粘到上面
Token 只存在你这台设备的浏览器里，不会发给任何人
