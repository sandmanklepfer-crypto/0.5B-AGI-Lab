# 0.5B+全库 系统 (本地可跑)

## 一句话
**把"需要记"的知识换成"需要算"的算子 —— 在可形式化域达到 300B 水平。**

## 组成
| 模块 | 内容 | 规模 |
|---|---|---|
| `ops_math.py` | 数学算子 27 个 | 代数/数论/组合/线代/微积分/概率/优化/信息论 |
| `ops_social.py` | 社科算子 20 个 | 博弈/运筹/社会选择/演化/偏好反推 |
| `lexicon.py` | 词典 349,045 词 + 55 词性 | 5 MB |
| `verifiers.py` | 验证器栈 6 层 | L1可执行/L2形式/L3检索/L3.5一致/L4重复/L5叙事 |
| `value_port.py` | 价值插口 3 桥 | 功利/义务/德性 (可切换可审计) |
| `core.py` | 统一调度器 | 意图路由 + 执行 + 审计 |
| `form_v3.py` | 形式库 (可组合原语) | 16 原语 + 组合器 |
