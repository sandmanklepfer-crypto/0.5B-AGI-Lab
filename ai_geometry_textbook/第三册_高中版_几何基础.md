## 第 1 章 向量：数字的排列

**向量**就是"一排数字"：

```
v = [3, 4]          (二维向量: 平面上的一个点/箭头)
w = [0.2, -0.5, 0.8, ...]   (896维向量: 模型里的一个概念)
```

**几何直觉**：
- 二维向量是平面上的箭头（从原点到点 (3,4)）
- 三维向量是空间中的箭头
- **896 维向量是 896 维空间中的箭头**——我们看不见，但数学一样适用

**向量的基本操作**：
- 加法：v + w = [3+0.2, 4+(-0.5), ...]（把两个箭头首尾相接）
- 数乘：2v = [6, 8]（把箭头拉长两倍）
- 长度（范数）：|v| = √(3² + 4²) = 5（箭头的长短）

**模型的每个概念都是一个向量**：
```
"猫" = 896维向量
"狗" = 896维向量
cos(猫, 狗) = 0.7  → 它们方向接近
```

**动手做**：拿两个概念向量，验证 cos 的公式：
```
cos(v,w) = (v₁w₁ + v₂w₂ + ... + v₈₉₆w₈₉₆) / (|v|·|w|)
```

## 第 2 章 投影：把一个方向"压"到另一个方向

**投影**：把向量 A 的影子"投"到向量 B 的方向上。

```
投影 = (A·B / |B|²) · B   (A 在 B 方向上的分量)
```

**直觉**：太阳从 B 的方向照过来，A 在地上投下的影子，就是 A 在 B 上的投影。

**在模型里的用途**：
1. **找"方向上的成分"**：想知道"这句话在推理方向上有多少"？——把它的向量投影到"推理方向"上，看投影有多长
2. **去除方向**：想"去掉模板的干扰"？——减去模板方向的投影分量
3. **正交**：投影为 0 = 两个方向完全无关（垂直）

**真实例子**（作者做的）：
- 想分离"推理"和"模板"（知乎）——测它们的方向夹角 cos = 0.85（很接近！）
- 因为太接近，投影过滤分不开它们——这是模型的"纠缠"问题（后面详讲）

**想一想**：如果两个方向 cos=0.85（很接近），能用一个方向"区分"另一个吗？（很难——这就是纠缠）

## 第 3 章 矩阵：变换的机器

**矩阵**是"数字的表格"，它的作用是**变换向量**：

```
矩阵 M（896×896）乘以 向量 v（896）→ 新向量 v'（896）
v' = M·v
```

**直觉**：矩阵是"变形机"——把一个箭头旋转、拉伸、压缩成另一个箭头。

**模型里的矩阵**：模型的每一层就是一个大矩阵（或几个），输入向量经过矩阵变换，变成新向量。**24 层 = 24 台变形机串联**。

**关键性质**：
- 矩阵可以叠加：M₁(M₂(v)) = 先经过 M₂ 再经过 M₁
- 矩阵的"名字"：权重（weights）——模型训练就是"拧这些矩阵里的数字"

**真实例子**：0.5B 模型的权重矩阵，896 行 × 896 列 ≈ 80 万个数字/层。24 层 ≈ 2000 万个数字（0.5B 参数的来历）。

## 第 4 章 SVD：找到最重要的方向

**SVD（奇异值分解）**：把一个矩阵拆成"最重要的方向"：

```
M = U·S·Vᵀ
S 的对角线上是奇异值（从大到小）——代表每个方向"多重要"
```

**直觉**：SVD 找出矩阵的"骨架"——少数几个最重要的方向，就能解释大部分变换。

**在模型里的用途**：
1. **降维**：把 896 维压到 256 维（保留主要信息）——"投影到主方向"
2. **找结构**：奇异值分布可以看出模型健不健康
3. **诊断**（作者用它）：死寂模型的奇异值分布正常——**说明病不在权重结构，在动力学**

**真实数据**（作者测的）：
- 正常模型和死寂模型的权重谱（奇异值）几乎一样
- 结论：**死寂不是权重坏了，是"动力学"卡了**（激活的行为，不是权重的结构）

**动手做**：对模型的权重矩阵做 SVD，画出奇异值分布——看它是否"平坦"（健康）还是"集中"（可疑）。

## 第 5 章 高维空间：看不见的几何

896 维空间长什么样？**我们看不见，但数学告诉它很"宽敞"**：

1. **高维空间非常大**：维度越高，空间体积增长越快——896 维空间里，两个随机向量几乎总是垂直的（cos≈0）
2. **高维空间很"空"**：数据在巨大的空间里只占一小块（所以模型用"流形"描述数据所在的小区域）
3. **高维的直觉**：把 896 维想象成 896 个"开关"，每个概念是一个"开关组合"——开关组合的数量巨大

**重要推论**：
- 模型的概念向量在高维空间里**距离很开**（一个萝卜一个坑）
- 如果它们**挤到一起**（距离都变小）——模型"坍缩"了（坏信号）
- **维度是模型的"容量"**：维度越高，能装的概念越多（但参数也越多）

**想一想**：为什么小模型（896 维）比大模型（比如 4096 维）容量小？——因为它的"房间"小，装不下太多概念。

## 第 6 章 动手做：SVD 找模型的主方向

**实验**：
1. 取 100 个概念的向量（896 维）
2. 拼成矩阵（100×896）
3. 做 SVD，看前几个奇异值占比

**预期结果**：
- 健康模型：前几个方向占比分散（信息分布在很多方向）
- 如果前 1-2 个方向占比特别高 → 概念都挤在一个方向 → 可疑

**真实数据**（作者测的死寂模型）：前 3 个奇异值占 52%——**不算低维坍缩，但概念聚集在一团**（吸引子的痕迹）。

**想一想**：SVD 告诉你的"主方向"像什么？（像地图上的主要山脉——大部分地形沿着它）

## 本册总结（记住这五句话）

1. 概念是向量（896 个数字），向量有方向、长度
2. 投影 = 把一个方向压到另一个方向（找成分/去干扰）
3. 矩阵 = 变形机（模型每层都是一台）
4. SVD = 找最重要的方向（诊断工具）
5. 高维空间很大很空——**概念挤在一起 = 坍缩 = 病**
