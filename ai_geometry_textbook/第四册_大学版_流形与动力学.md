> 前三册：向量、矩阵、SVD 是"静态"工具。

## 第 1 章 激活空间：模型的"思考空间"

**激活**：模型处理一个词时，每一层中间产生的向量叫"激活"（hidden state）。

```
输入"猫" → 层1激活 → 层2激活 → ... → 层22激活 → 输出
          a₁        a₂              a₂₂
每个激活是 896 维向量 —— 模型的"想法快照"
```

**激活空间**：所有可能的激活组成的 896 维空间。模型思考 = 在激活空间里"走"。

**关键**：
- 不同概念 → 不同的激活区域
- 同一概念的不同说法（"高兴""开心"）→ 激活几乎一样（在同一个位置附近）
- **模型判断"两个想法像不像" = 看激活离得近不近**

**动手做**：取"高兴"和"开心"的层 22 激活，算 cos——你会发现它们非常接近（0.9+）。

## 第 2 章 流形：数据长在哪张曲面上

**流形**：数据不是均匀分布在空间里，而是**长在一张"曲面"上**。

**直觉**：地球表面是三维空间里的二维曲面——地球上的点都"长"在球面上，不在球外面。模型的概念也长在激活空间里的一张"曲面"上，叫**数据流形**。

**为什么重要**：
1. **模型只知道流形上的内容**（流形外的东西它没见过）
2. **流形是"弯曲的"**：沿着流形走 = 想法自然变化；离开流形 = 变成乱码
3. **流形决定"能走多远"**：模型推理 = 在流形上从一个概念走到另一个概念

**真实例子**：
- "高兴"→"开心"→"兴奋"→"激动"：在流形上一路平滑移动（近邻概念）
- "高兴"→"数学"：流形上没有近路（要走很远）——模型容易迷路

**想一想**：模型的"创造力" = 在流形上走一条没人走过的路。走歪了（离开流形）= 乱码。

## 第 3 章 对称性：变换不变的结构

**对称性**：一个东西经过某种变换后**不变**，就说它有这个变换的对称性。

```
圆：转任意角度都一样（旋转对称性）
正方形：转90°、180°、270°一样（离散旋转对称性）
```

**模型的对称性（G_sem 不变群）**：同一概念换一种说法，激活应该不变：

```
"高兴" 和 "开心" → 激活应该几乎一样（语义不变性）
"猫在睡觉" 和 "猫咪在睡觉" → 激活应该几乎一样
```

**为什么对称性重要**：
1. **稳定性**：有对称性的模型，换个说法也能认出来（泛化）
2. **锚定**：概念簇稳定（同一个概念不管怎么说，都在同一个位置）
3. **训练方法**：教模型"换说法激活不变"（对称性损失）——作者在 v4 系列用过

**诚实说明（重要）**：对称性的"锚定功劳"后来被证伪了（模型本来就会锚定）——对称性的独立价值**未经验证**。但它作为"训练内容"（教什么）和"诊断工具"（测激活稳定性）仍然可用。

**动手做**：测"高兴"和"开心"的激活 cos——这就是在测模型的"对称性保持得好不好"。

## 第 4 章 吸引子：状态被吸向哪里

**吸引子**：一个"吸力点"——附近的状态都会被吸过去。

```
想象弹珠在碗里滚：不管从哪放手，最后都滚到碗底（吸引子）
```

**模型的吸引子**：
- 正常模型：有很多吸引子（每个概念簇一个）——"猫"被吸向猫簇
- 生病模型：**一个超级吸引子**把什么都吸过去——所有状态都掉进同一个"坑"

**真实发现**（作者解剖死寂模型）：
- 死寂模型的"超级吸引子"吸走了 40% 的输入
- 被吸进去后，模型开始重复输出零散碎片（"ascu""彪彪""!!!"）
- 这个吸引子的"捕获域"极深——**任何干预都拉不出来**（20+ 种方法试过）

**术语**：
- **吸引子**：吸力的点
- **盆地**：被吸住的区域
- **捕获域**：吸力范围
- **极限环**：状态绕着圈转（循环）

**关键教训**：吸引子是正常的（每簇一个），**一个超级吸引子 = 病**（所有概念被吸到一处 = 模型"想不出新东西"）。

## 第 5 章 Lyapunov 指数：轨迹是发散还是收敛

**Lyapunov 指数**：衡量"相邻的轨迹是分开还是靠近"——动力学的"温度计"。

```
两条几乎一样的轨迹:
  越走越远 → Lyapunov > 0（混沌: 蝴蝶效应）
  越走越近 → Lyapunov < 0（收敛: 被吸到一起）
  不远不近 → Lyapunov ≈ 0（临界）
```

**模型的测量（活性 = 相邻步激活变化率）**：
```
活性 = 1 - cos(上一步激活, 这一步激活)
```

**真实数据**（作者测的）：
- 正常模型：活性 0.24（轨迹活跃，每步都在变）
- 死寂模型：活性 0.046（轨迹死寂，几乎不动）
- 对比大模型：32B 的活性 0.36（比 0.5B 正常还活跃）

**重要发现**：
1. **活性 < 0.05 = 死寂预警线**（要卡住了）
2. **大模型更活跃**（32B 0.36 > 0.5B 0.24）——大模型"想得更开"
3. **死寂 = 动力学"冻结"**（不是权重坏了，是行为卡了）

**这就是全书最重要的工具**：一个数（活性）预报模型状态。训练时监控它，0.05 以下就停。

## 第 6 章 极限环与直线锁定：重复的几何

模型重复说话（"答案答案答案"）的几何是什么？

**直觉猜测**：以为是"循环"（极限环）——状态绕着圈转。

**真相（作者用 3D 投影验证）**：**不是环，是直线**！

```
死寂轨迹 3D 投影（14 步）:
t0 → t1 → ... → t13  一条平滑直线（方向几乎不变, cos 0.90）
起点到终点很远（没绕回来）
→ 不是循环! 是"方向锁定的直线滑行"
```

**精确几何**：
- 模型卡住时，激活沿**一个固定方向单调滑行**
- 输出的 token（字）不变，因为 logits（得分）的 argmax 没变
- **"重复说话"的真相**：不是绕圈，是"在一条直线上滑，但出口（字）锁死了"

**为什么这重要**：
1. 修正了直觉（不是环，是线）
2. 解释了为什么"打断"难救：回到直线上任何点，都继续沿锁定方向滑（方向锁死，与位置无关）
3. 需要的是"换方向"（强干预），不是"换位置"（回退）

**想一想**：如果一辆车锁死了方向盘（只能直走），你让它"倒回去"有用吗？（没用——它还是直走。要修方向盘，或换条路。）

## 第 7 章 动手做：测量模型的"活性"

**实验**：
1. 取一个模型，问它"你好"
2. 让它生成 15 个字
3. 每一步记录层 22 的激活
4. 算相邻两步的活性（1-cos）

**预期**：
- 健康模型：活性一直在 0.1-0.3（正常波动）
- 模型开始重复时：活性骤降到 0.05 以下（死寂预警！）

**练习**：找出模型"开始重复"的那一步，看活性是不是在那一步之前就开始下降——**活性是"提前预报"**。

## 本册总结（记住这五句话）

1. 激活 = 模型的"想法快照"（896 维向量），思考 = 在激活空间走
2. 概念长在**流形**（曲面）上——离开流形 = 乱码
3. 对称性 = 换说法激活不变（稳定性，独立价值待验证）
4. **吸引子**把状态吸向自己——一个超级吸引子 = 病
5. **活性 < 0.05 = 死寂预警**（Lyapunov 温度计）；死寂 = 直线锁定（不是环）
