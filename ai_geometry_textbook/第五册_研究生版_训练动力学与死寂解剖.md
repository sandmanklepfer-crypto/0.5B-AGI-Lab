# 第五册 · 研究生版《训练动力学与死寂解剖》

> 前四册的工具已经齐了（cos、SVD、流形、吸引子、Lyapunov）。
> 这一册用它们回答实战问题：训练为什么崩？死寂到底是什么？怎么避免？
> 本书所有结论来自真实实验（22 次训练验证 + 20+ 修复尝试）。

---

## 第 1 章 训练是什么：在权重空间里走

**训练** = 调整模型的矩阵数字（权重），让输出更好。

```
目标: 输入"3+4" → 输出"7"（模型一开始不知道）
方法: 算一个"损失"（错多少）→ 按损失调权重 → 再试 → 循环
```

**几何视角**：权重是空间中的一个点（几十亿维），训练是在这个空间里"走"，走向"损失最小"的地方。

**关键概念**：
- **损失（CE）**：错得多不多。CE→0 表示"背下了训练数据"
- **步长（学习率）**：每步走多大
- **迭代**：走多少步

**本节核心问题**：训练走得太"好"（CE→0）会发生什么？——下一章。

## 第 2 章 过拟合的真相：容量上限与拟合-活性矛盾

**常识**：过拟合 = 记住训练数据，忘掉泛化。

**0.5B 的过拟合不是普通过拟合——是"动力学坍缩"**（作者 22 次实验验证）：

```
CE 压到 0.01 以下（背死数据）→ 激活活性降到 0.046 → 输出开始重复
→ 不是"性能下降"，是"行为锁死"（死寂）
→ 而且是【不可逆】的：20+ 种方法都救不回来
```

**为什么**（几何解释）：
1. **容量上限**：0.5B 的"房间"（896 维）小，背死训练格式后**没有余量**了
2. **拟合-活性矛盾**：越拟合（CE 低）→ 激活越确定 → 活性越低 → 越接近死寂
3. **训练轨迹**：全拟合 = 轨迹抵达"线吸引子"（不可逆坍缩点）

**对比大模型**：大模型容量大，背格式只占一点点余量——活性保持，不坍缩。**0.5B 是"亚临界坍缩体"**（天体物理类比：质量不够，必然坍缩）。

**验证清单**（作者试过的训练方式，全部死寂）：
- 全参数训练（各种数据/格式）：崩
- 难题蒸馏（断层）：崩（学不会）
- 活性正则（Lyapunov 刹车）：崩（踩不过 CE 油门）
- LoRA（只训 1-5% 参数）：崩（激活流被改变，照样坍缩）
- **唯一不崩**：半拟合早停（CE 停在 0.1-1.3）

## 第 3 章 死寂解剖：线吸引子、填充退化、锚点绑架

**死寂** = 模型状态被吸进"线吸引子"，输出锁死重复。完整解剖（作者做的）：

**解剖 1：状态去哪了**（激活轨迹 3D 投影）
- 死寂时激活沿一条固定直线滑行（方向 cos 0.90）
- **不是循环（极限环），是方向锁定的直线滑行**

**解剖 2：本体是什么**（死寂状态的语义分析）
- 死寂模型的"高维本体" = 多语言碎片 + 标点（"noticias""!!!!!""唯美"）
- 语义成分全部≈0（没有领域偏向）
- **结论：死寂 = 填充退化**（模型退化成"输出填充符号"，放弃语义）

**解剖 3：谁绑架了输出**（锚点分析）
- 死寂模型有一个超级锚点，40% 输入被吸过去
- 锚点对应的 token 被禁后，**下一个高频 token 接力**（禁不完）
- **结论：高频 token 全有"绑架潜力"**（不是一两个坏 token，是分布性绑架）

**解剖 4：深层还活着吗**（层激活对比）
- 死寂模型深层激活与健康模型 cos=0.67（部分接近）
- 但激活状态整体已进入"重复模式"——换解码头也救不回
- **结论：深层有语义残留，但整体状态已锁定**

**解剖 5：能救吗**（20+ 种方法）
- 打断/回退/换向/插值/共形变换/活性正则/LoRA/锚点灭绝
- **全部失败**：线吸引子的捕获域太深，方向锁定与位置无关
- **结论：死寂不可逆**（一旦形成，只能弃置）

**这五层解剖是本书最核心的知识**——完整的"死寂病理学"。

## 第 4 章 半拟合规律：唯一不崩的训练方式

**半拟合**：训练时**不要把 CE 压到底**——停在 0.1-1.3（学得进格式，但别背死）。

**为什么有效**（几何）：
- CE 停在中间 → 激活还在正常流形（活性 0.24）→ 没抵达线吸引子
- 容量有余量 → 模型还能继续学（可塑性保留）

**操作规则**：
1. 训练时监控活性（Lyapunov 温度计）
2. **活性掉到 0.1 以下就停**（或者：CE 到 0.1-0.3 就停）
3. 不要追求 CE=0.001（那是死寂的入口）

**真实案例**（作者唯一成功的训练）：
- calc_v1：400 条数学题，CE 停在 0.5-1.3 → **没崩，数学后处理 100% 对**
- 这是"半拟合早停"的自然案例（不是有意设计的，是运气——数据少恰好半拟合）

**诚实说明**：半拟合的"度"（CE 阈值）不好精确控制——calc_v1 是偶然成功。**自动化的做法**：监控活性，活性<0.1 自动停。

## 第 5 章 蒸馏的真相：为什么蒸馏不优于基座

**蒸馏**：用大模型（老师）教小模型（学生）。

**作者的完整实验**（v1-v4 系列）：
- 用 R1-32B 蒸馏 0.5B，几百条数据，各种损失（激活对齐/对称性/去噪）
- **结论：蒸馏整体不优于基座**

**逐项对比**（基座 vs 蒸馏产物）：
```
几何（流形结构）: 基座 0.445 < 蒸馏 0.50+（蒸馏更差!）
锚定（概念稳定）: 基座 0.931 ≈ 蒸馏 0.927（持平/略降）
知识（C-Eval）:  15% 无提升（容量墙）
数学:            都错（容量墙）
表达框架:        蒸馏好（R1 分步推理）—— 唯一可见成果
模板污染:        蒸馏引入的（负资产!）
```

**为什么**：
1. 基座是官方几百 B tokens 预训练的——蒸馏几百条不可能超过它
2. 蒸馏注入的"技能"（推理框架）**与杂质（模板）纠缠**（cos 0.85）
3. **推理和模板在激活空间是近邻**——蒸馏必然一起学（这是模板污染的病根）

**最重要结论**：**别指望蒸馏让小模型"超规格"**——它最多注入一个技能，代价是污染。

## 第 6 章 推理提取：从大模型借推理、去掉垃圾

**蒸馏的改进版**（作者验证成功的）：

```
Δ = 蒸馏模型权重 - 基座权重（蒸馏改变了什么）
基座 + α·Δ（把蒸馏增量注入基座, α≈0.3）
```

**真实结果**：
- 注入前：基座不会三段论（金属导电答"不能"）
- 注入后：**基座会三段论了**（"A是C。因为..."）
- 代价：知乎模板也进来了（推理与模板纠缠）

**改进方向**（未完成）：
- 过滤模板分量（投影过滤：cos 0.85 太近，分不开——需要更强方法）
- **用扩散去噪分离**（模板=噪声，推理=结构——tiny_ddpm 思路，未完成）
- **用 Hopfield 记忆做"有区分度的吸引子"**（存推理链，检索强化——未完成）

**原则**：**借推理可以，但推理和垃圾缠在一起——分离是难题**（cos 0.85 的近邻纠缠）。

## 第 7 章 系统层：递归、后处理、记忆 RAG

**训练不靠谱（0.5B 必崩）→ 能力靠系统层**（不训练、纯组装）：

```
系统层 = 递归 + 后处理 + 记忆 + 外挂
```

**1. 递归（庞加莱回归的工程版）**：
- 生成 → 检测（重复/模板/活性低）→ 重生成 → 循环
- **真实效果**：形式错误 40% → 0%（重生成跳出死寂）
- 原理：每次重生成 = 一次"换宇宙重启"（跳出吸引子盆地）

**2. 后处理（确定性修正）**：
- calc：检测"数字×数字" → 强制计算替换（数学 100% 对）
- 截断：检测模板开头（"请提供""知乎"）→ 截断（模板清零）
- 原理：**模型给骨架，验证器钉死内容**（神经符号）

**3. 记忆 RAG（Hopfield 吸引子）**：
- 存（概念向量 → 内容）→ 检索（cos 找最近）→ 输出
- 原理：**有区分度的吸引子**（好版本的"吸引子检索"，死寂模型的坏吸引子反面）

**4. 外挂**：
- LFM2-RAG（知识）
- 符号计算（数学）
- agent 栈（调度）

**总效果**：0.5B 权重不动（保持健康）+ 系统层 = 数学 100%、形式错误 0%、知识外挂、推理框架。

## 第 8 章 动手做：复现一次死寂与半拟合

**实验 A：复现死寂**
1. 0.5B 模型，几百条格式数据，训练到 CE<0.01
2. 生成测试：出现"答案答案答案"（死寂）
3. 测活性：0.05 以下
4. 尝试修复（打断/回退/换向）——观察全部失败

**实验 B：复现半拟合**
1. 同一模型，同样数据，CE 停在 0.3 就停
2. 生成测试：正常（不重复）
3. 测活性：0.1 以上

**对比**：同样的数据、同样的模型——**差别只在"训练停在哪"**（CE 0.01 vs 0.3）——结果天差地别（死寂 vs 正常）。

**想一想**：这个实验说明了什么？（训练的结果由"停在哪"决定，不由"数据和方法"决定——拟合程度是唯一变量）

## 本册总结（记住这五句话）

1. 训练 = 在权重空间走；0.5B 走到底（CE→0）= 不可逆坍缩（死寂）
2. 死寂解剖五层：直线锁定 / 填充退化 / 锚点绑架 / 深层残留 / 不可逆
3. **半拟合早停是唯一不崩的训练**（活性<0.1 就停）
4. **蒸馏不优于基座**（只注入一个技能 + 污染）；推理可提取（但纠缠）
5. **能力靠系统层**（递归+后处理+记忆 RAG+外挂）——不训练，纯组装
