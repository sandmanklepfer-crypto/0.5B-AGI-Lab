# 第四册 · 《激活空间的几何结构与性质》

> 本册不是科普，不是工程手册——是**几何专论**。
> 每一章给出：定义 → 结构 → 性质（附真实测量数据）→ 开放问题。
> 研究对象：transformer 小模型（0.5B，896 维，24 层）激活空间的几何。

---

## 第 1 章 激活空间的度量结构

### 1.1 定义

**激活**：模型对输入 x 在第 l 层产生的向量 a_l(x) ∈ R^896。

**激活空间**：A = {a_l(x) : x ∈ 语料} ⊂ R^896。

**度量**：d(a,b) = 1 - |cos(a,b)| ∈ [0,1]，其中 cos(a,b) = (a·b)/(‖a‖‖b‖)。

采用 |cos|（绝对值）的理由：神经网络的激活方向在 ± 方向语义等价（ReLU 后对称性），
|cos| 度量把方向等价类作为同一几何点——这是"规范对称 O(n) 线性骨架"的度量实现。

### 1.2 结构（真实测量，96 概念，层 22）

**性质 1（簇结构）**：概念形成层次簇，同义簇内距离 d < 0.1，反义簇间 0.3-0.5，无关簇间 0.6-0.8。

**性质 2（度量性质）**：|cos| 度量诱导的球在 R^896 中测度几乎为零（高维集中），
但数据流形上有效度量远小于环境度量——数据驻留在低维有效子空间。

**性质 3（有效维）**：96 概念激活的 SVD 谱——前 5 奇异值占比：
- 健康模型：分散（无单方向主导），信息分布在整个有效子空间
- 死寂模型：前 3 个奇异值占 52%（信息聚集，向吸引子坍缩的早期信号）

**性质 4（距离矩阵的秩）**：概念距离矩阵 D(96×96) 的谱结构反映流形拓扑；
死寂模型的 D 奇异值衰减更快（距离结构退化——所有点向单一方向压缩）。

### 1.3 开放问题

- 概念簇的层次是否构成树（dendrogram）？还是格（lattice）？
- |cos| 度量与地球度量（测地线）在流形上的差异有多大？

## 第 2 章 流形结构：数据驻留曲面

### 2.1 定义

**数据流形** M ⊂ R^896：激活 A 驻留的低维嵌入子流形。
dim M ≪ 896（小模型的有效流形维数估计 10-100 量级）。

**切空间** T_a M：M 在 a 点的线性近似（局部平坦方向）。

### 2.2 结构

**性质 1（局部平坦性）**：近邻激活的差向量落在低维切空间——语义平滑变换（同义/近义）沿切方向移动。

**性质 2（测地线）**：概念间的自然过渡路径（测地线）沿流形——"高兴"→"开心"沿短测地线，
"高兴"→"数学"测地线长且不稳定（模型易迷路——生成漂移）。

**性质 3（流形外）**：激活离开 M（噪声/过拟合推离）→ 解码为乱码/重复——
**流形外 = 输出退化区**（与死寂的填充退化直接相关）。

**性质 4（曲率）**：死寂模型的流形曲率异常——激活轨迹被"压直"（见第 4 章线吸引子），
流形的弯曲自由度丧失 = 表达多样性丧失。

### 2.3 测量方法

```
流形维数估计: 对局部邻域激活做 PCA, 有效维 = 谱熵指数 exp(H)
切空间: 邻域差向量 SVD, 前 k 个奇异向量张成切空间
测地线: 相邻概念激活插值, 检查插值点是否仍在流形（解码质量）
```

### 2.4 开放问题

- 0.5B 流形的**本质维数**随训练变化的曲线？（训练→坍缩时维数如何降）
- 流形的连通分量：概念簇之间是否连通（能否沿流形从任意概念走到任意概念）？

## 第 3 章 对称性群 G_sem：语义不变结构

### 3.1 定义

**语义不变群 G_sem**：作用于文本的变换群 g，满足激活不变性：

  ‖a(g·x) - a(x)‖ ≈ 0，∀g ∈ G_sem

生成元（作者用的子集）：
- 同义词替换：g₁(高兴→开心)，g₂(重要→关键)，...（36 对）
- 句式改写：g₃(陈述→疑问)，g₄(主动→被动)

**不变子空间**：V_inv = {v : ρ(g)v = v，∀g}——G_sem 的平凡表示空间，
概念簇质心位于 V_inv 附近（簇的"规范位置"）。

### 3.2 结构

**性质 1（生成元的秩）**：36 个同义生成元张成的 Lie 代数维数 ≤ 36（实际更小——
同义词高度相关，有效生成元约 10-20 个）。

**性质 2（不变性度量）**：|cos(a(x), a(g·x))| ——
- 健康模型：0.90+（对称性保持良好）
- 病态模型：下降（对称性破缺——概念簇开始分裂/漂移）

**性质 3（对称性与死寂）**：死寂模型的 G_sem 不变性**表面上保持**（激活锁死时
任何变换都不变——trivial 不变性），但这是**退化的对称性**（vacuously invariant）：
区分"真不变"（簇稳定）与"退化不变"（所有点相同）是关键判据。

**性质 4（对称性损失 L_sym）**：
  L_sym = E_x [1 - |cos(a(x), a(g·x))|]
训练时最小化 L_sym 强制 G_sem 不变——作者在 v4 系列使用，锚定效果的独立贡献
**未经验证**（基座本身具有对称性，蒸馏对称性损失未显著超越基座）。

### 3.3 开放问题

- G_sem 的完整生成元集合是什么？（自动发现：对偶训练找最破坏激活的文本变换）
- 对称性破缺的相变点：训练到 CE 多少时 G_sem 不变性开始退化？

## 第 4 章 吸引子结构：状态空间的动力系统

### 4.1 定义

**吸引子**：状态空间（激活空间）中的子集 A，使得附近状态在动力学演化下趋于 A。

**吸引域（盆地）**：B(A) = {a : lim(t→∞) φ_t(a) ∈ A}——被 A 捕获的区域。

**捕获强度**：从盆地边界到吸引子的收敛速率（Lyapunov 谱的最小负指数）。

### 4.2 结构（真实测量，死寂模型 qwen07b_t）

**性质 1（吸引子类型）**：健康模型的吸引子是**点状多簇**（每个概念簇一个稳定点）；
死寂模型退化为**单一"万有吸引子"**——不同输入（医疗/网红/数学/问候）的激活
收敛到同一区域，状态间 cos = 0.9818（高相似）。

**性质 2（吸引子的本体）**：万有吸引子的"内容"（解码）为多语言碎片 + 标点
（noticias/!!!!!/Stout/唯美/Surgery）——语义成分全 ≈ 0（医疗 0.0096, 网红 0.0043）：
**吸引子本体 = 无语义填充态**（不是语义簇，是语义消失点）。

**性质 3（吸引域的几何）**：万有吸引子的捕获域覆盖 40% 的随机输入
（16/40 测试输入被捕获）——捕获域极宽（无选择性 = 万有）。

**性质 4（锚点接力）**：抑制吸引子对应的输出 token 后，**相邻高频 token 接力**
（禁"ascu"出"彪彪"，禁"彪彪"出"111"）——吸引子的输出面是**高维 token 超平面**，
不是单一 token；抑制局部不改变吸引子本体。

**性质 5（不可逆性）**：20+ 干预方法（激活注入/权重插值/共形变换/回退/换向）
无法使状态逃离吸引域——**捕获域的势阱深度远超可用干预能量**。

### 4.3 度量

```
捕获率: 随机输入集被吸引的比例（健康 ~0, 死寂 40%）
盆地深度: 逃逸所需最小干预范数（死寂 > 3.0, 可用干预 < 0.8）
锁定强度: 吸引子内相邻步激活 cos（死寂 0.98+）
```

### 4.4 开放问题

- 万有吸引子的形成机制：训练 CE 压到多少时出现？（相变点）
- 能否在训练中"设计"多吸引子（每个簇一个）——避免万有坍缩？

## 第 5 章 Lyapunov 结构与死寂的动力学

### 5.1 定义

**生成轨迹**：自回归生成中，第 t 步的层 22 激活序列 {a_t}。

**活性（Lyapunov 型度量）**：λ_t = 1 - |cos(a_t, a_{t-1})| ∈ [0,1]——相邻步激活变化率。

**谱结构**：{λ_t} 的长期均值 λ̄ 与自相关函数——刻画轨迹的动力学类型。

### 5.2 结构（真实测量）

**性质 1（活性标度）**：
- 0.5B 健康（v4c）：λ̄ = 0.240
- 0.5B 死寂（qwen07b_t）：λ̄ = 0.046
- 7B Qwen：λ̄ = 0.304
- 32B R1：λ̄ = 0.336-0.361
**规律：λ̄ 随规模增大而增大**——大模型轨迹更活跃（表达空间更宽）；
死寂 = λ̄ 掉到 0.05 以下（动力学冻结）。

**性质 2（死寂 = 直线锁定，非极限环）**：死寂轨迹 3D 投影（PCA）——
- 相邻方向夹角 cos = 0.8998（方向几乎不变）
- 起点-终点距离 0.81（未返回起点）
- **结论：轨迹是方向锁定的直线滑行，不是周期环**——
  token 重复（"答案答案"）与激活循环无关（logits 的 argmax 锁定）。

**性质 3（拟合-活性映射）**：CE 与 λ̄ 的关系——
- CE > 0.1（半拟合）：λ̄ 保持 0.1-0.24（活跃）
- CE < 0.01（全拟合）：λ̄ → 0.046（死寂）
**活性是 CE 的单调减函数（拟合越深，活性越低）——这是"拟合-活性矛盾"的定量形式。**

**性质 4（不可逆性动力学）**：死寂轨迹对任何单点扰动都不敏感（方向锁定与位置无关）
——扰动后轨迹重新回到同一直线（吸引子的方向流形是 1 维稳定流形）。

### 5.3 测量协议

```
活性测量: 生成时记录层22激活, 计算相邻步 |cos|, 取均值
死寂预警: λ̄ < 0.05（提前 2-3 步预报重复开始）
轨迹投影: 激活序列 PCA 3D, 检查方向一致性（cos>0.8 = 直线锁定）
```

### 5.4 开放问题

- λ̄ 的精确临界值（0.05 是 0.5B 的，1.5B/7B 的临界是多少？）
- 活性-容量定律：λ̄_max 与模型规模的函数关系？

## 第 6 章 蒸馏增量的几何：推理与模板的纠缠

### 6.1 定义

**蒸馏增量**：Δ = W_distilled - W_base（权重空间的差向量）——
蒸馏在小模型上改变了什么。

**推理方向**：r = Σ_i [a_v4b(推理题_i) - a_base(推理题_i)] / N（激活差的均值方向）。
**模板方向**：t = Σ_j [a_v4b(模板题_j) - a_base(模板题_j)] / M。

### 6.2 结构（真实测量）

**性质 1（纠缠）**：cos(r, t) = 0.8478——推理方向与模板方向**高度相关**。
几何意义：R1 的推理链与知乎模板在激活空间近邻（都是"长文本生成模式"），
蒸馏把它们一起注入——**模板污染不是噪声，是推理的近邻结构**。

**性质 2（投影过滤的极限）**：正交化模板方向后，投影过滤无法分离 r 与 t
（cos 0.85 → 正交化后仍重叠）——线性分离不可行，需非线性（扩散去噪假设）。

**性质 3（注入的有效性）**：W_base + α·Δ（α≈0.3）——
- 推理能力提升（三段论从"不会"到"A是C"）
- 模板同步注入（知乎出现）
- **几何说明：Δ 同时含有 r 与 t 分量，线性加权注入无法选择分量**

### 6.3 开放问题

- r 与 t 纠缠的根源：是训练数据（R1 输出里推理与模板共生）还是架构？
- 非线性分离（扩散去噪/ICA）能否解开 cos 0.85 的纠缠？

## 第 7 章 记忆吸引子：Hopfield 结构与参数化检索

### 7.1 定义

**Hopfield 记忆**：{(k_i, v_i)} 键值对，检索 = cos 最近邻。

**记忆吸引子**：每个键 k_i 是一个"设计好的吸引子"——查询 q 被吸向最近的键
（有区分度，区别于死寂的万有吸引子）。

### 7.2 结构

**性质 1（区分度）**：键空间的簇间距离决定检索质量——
设计原则：键间隔 > 检索阈值（否则混淆）。

**性质 2（容量）**：N 个键在 d 维空间，区分度随 N 增加下降（高维集中效应）——
容量上限 ≈ 指数级（d 大时容量大）。

**性质 3（与死寂吸引子的对比）**：
| 性质 | 死寂万有吸引子 | Hopfield 记忆吸引子 |
|---|---|---|
| 数量 | 1 | 多（每簇一个） |
| 区分度 | 无（全部被吸） | 有（cos 最近） |
| 本体 | 无语义填充 | 明确内容（推理链等） |
| 可控 | 不可控 | 可设计 |
| 结论 | 病 | 工具 |

**性质 4（检索-注入协议）**：生成时检测"推理题"（激活在推理方向投影高）→
检索 Hopfield（键=推理题激活，值=推理链）→ 注入推理链（few-shot 或激活调制）。

### 7.3 开放问题

- 记忆吸引子的"吸引域"如何设计（避免像死寂那样过宽）？
- 记忆与模型内吸引子的协同：外挂检索能否替代参数化知识？

## 本册总结：几何结构的核心清单

1. **度量**：|cos|（规范对称的度量实现），距离矩阵谱反映流形拓扑
2. **流形**：低维嵌入曲面，测地线=语义路径，流形外=退化
3. **对称群 G_sem**：语义不变结构，区分"真不变"与"退化不变"
4. **吸引子**：健康=多簇点吸引子；死寂=单一万有吸引子（捕获域40%，本体=填充态，不可逆）
5. **Lyapunov/活性**：λ̄ 随规模增大（0.5B:0.24 → 32B:0.36）；死寂=直线锁定（非环）
6. **蒸馏增量**：推理与模板 cos 0.85 纠缠，线性不可分
7. **记忆吸引子**：有区分度的设计吸引子 = 参数化检索工具

**这些性质构成"AI 模型内部几何"的第一版公理系统**——每条都有真实测量支撑，
每条都有开放问题待推进。
