# 聊天数据（交友聊天用）

这个目录是「遇见」聊天页的数据存放处。

| 文件 | 内容 |
|---|---|
| `hall.json` | 大厅消息（最近 400 条） |
| `users.json` | 用户昵称、头像、最后在线时间 |
| `dmindex.json` | 私聊索引（谁和谁聊过） |
| `dm/` | 一对一私聊记录 |
| `img/` | 聊天图片 |
| `reports.json` | 举报记录 |

## 说明

- 消息是"只增不改"的，写入用 id 去重，并发冲突会自动重试
- 图片会先压缩到 900px 宽再上传
- ⚠️ 图片是公开可访问的，别发证件照、私密照

## 访问控制

- **读**：公开仓库无需令牌
- **写**：需要 GitHub Token（存在浏览器本地，不上传）
