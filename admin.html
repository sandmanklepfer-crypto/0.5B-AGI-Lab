怎么拿到 GitHub Token？（30 秒）
  1. 打开 github.com/settings/personal-access-tokens/new
  2. Token name 随便填，例如 luhuo-admin；Expiration 选 90 天或自定义
  3. Repository access 选 Only select repositories → 勾选你这个店铺仓库
  4. Permissions → Repository permissions → 找到 Contents 选 Read and write
  5. 点 Generate token，复制以 github_pat_ 开头的字符串，粘到下面

Token 只存在你自己手机的浏览器里，不会上传到任何地方。别把它发给别人。

日常怎么用

1. 打开这个后台 → 改价 / 加菜 / 发券
2. 点右上角 💾 保存并发布
3. 等 30 秒～1 分钟，顾客刷新页面就能看到新价格
4. 顾客下单后，地址电话会按你设置的方式发给你；你也可以在微信里直接和他确认

关于"线上支付"

现在用的是收款码方式：顾客下单 → 看到你的微信/支付宝收款码 → 扫码付款 → 把订单发给你。
个人做卤货生意这个最常见也最省事（钱直接进你微信钱包，不用提现手续费）。
以后如果想做成"点一下就直接扣钱"，需要营业执照 + 微信支付/支付宝商户号，还要一台服务器，可以再升级。

安全提醒

· 这个后台网址别人也能打开，但没有你的 Token 就改不了任何东西，所以不用怕。
· 第一次打开会让你设一个 4 位数字锁，只是防止别人拿你手机乱点。
· 千万别把 Token 截图发出去。
