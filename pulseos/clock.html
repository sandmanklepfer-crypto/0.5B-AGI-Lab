这一页是什么

钟表的指针角度是在生成页面时算好并写死的。所以它不是实时时钟， 是一个快照——指针停在哪，数据就是那一刻的。

这样做的好处：不需要 JS。视觉模型截图后能从指针位置直接读出时间， 纯文本 AI 读上面的 UTC 时间戳就行。

为什么 CSS 做不到，SVG 可以

CSS 动画  →  只能「转」，不能显示【真实当前时间】
SVG      →  指针角度 = f(时, 分, 秒)，在 bake 时算出来
            静态写进 <line x2= y2= />，零 JS 也能被看见

页面里有一个隐藏的 <img> 指向上面这个地址， 带 ?t=1792994207175 是为了绕过 GitHub 的 Cache-Control: max-age=600（实测缓存 10 分钟）。

必须说清的边界

① 只有「真的渲染页面」的 AI（headless Chrome / Playwright / 带浏览的 ChatGPT、Perplexity） 才会去请求那个 <img>。纯文本 AI 只读源码，图片不会被加载。

② GitHub Pages 收到这个 GET 后什么都不做 —— 它不记日志、不执行代码。 想真的记录或触发，信标得指向你自己的 Cloudflare Worker。

③ 现在信标指向 GitHub Pages 自己，所以它只会发一次请求，然后什么都没有。 这不是 bug，是静态托管的物理限制。
