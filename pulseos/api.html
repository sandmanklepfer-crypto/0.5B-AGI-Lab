给 AI 的说明（请先读这段）

1. 机器可读版本：pulse.json（含 capabilities 与 gateway 字段）
2. 先查 gateway.available。若为 false，说明没有在线网关， 任何调用都会失败。请勿假设可用。
3. 在线状态在 pulse-health.json，含 online 与 gateway_url。
4. 调用方式：POST {gateway.invoke.url}， body = { capability, params, request_id }
5. 控制面只传路牌：args 上限 64 KB。大文件请传 URL 或路径，不要塞进 args。

03怎么用

方式 A：有在线网关（跨机）

curl -X POST https://你的网关/invoke \
  -H 'Content-Type: application/json' \
  -d '{
    "capability": "invoke",
    "params": { "service": "echo", "op": "ping" }
  }'

# → { "ok": true, "result": { "pong": 1 }, "ms": 9.06 }

方式 B：没有网关，自己跑一份

git clone https://github.com/sandmanklepfer-crypto/0.5B-AGI-Lab
cd 0.5B-AGI-Lab/pulseos
node shell/gateway.js --port 8899 --mode local

方式 C：不需要网络，直接当库用（最快，p50 = 417 ns）

const pulse = require('./index');
const rt = pulse.create({ dir: './state' });
rt.deploy('service c { state { n: int = 0 } on "inc" { set n = n + 1 return n } }');
const r = rt.invoke('c', 'inc', []);
// { ok: true, result: 1, ms: 0.0004 }

04关于「无穷子域名」

做不到，也不该做。

GitHub Pages 只提供 用户名.github.io/仓库名/ 这一种路径路由。 没有通配 DNS，不能为每个微内核开一个子域名。

而「寻址」本来就不需要子域名 —— pulse.json 里的 capabilities[].id 就是地址。一个静态 JSON 能描述无数个能力，成本为零。
