# 正式资产: 检索-匹配断层 V127 — 纠错对训练裁决 (去噪头装上但装歪)

## 状态: ✅ 已裁决 (2026-09-08) | 载体: qwen25_base_raw (0.5B) + LoRA | 文件: v127_train_test_correction.py

## 实验
给0.5B装"去噪头": 用 错转述→对转述 纠错对(9卡×错法=22对), LoRA(r=8, 120步)教"对照卡→改口"
loss只算改口段; 测: seen卡(记忆) + unseen卡(泛化:自发转述/改正)

## 结果
### 训练
loss: 0.0513 → 0.0001 (120步收敛完美, 84秒) | trainable 4.4M (0.88%)
### base (未训练, 对照)
- 自发转述: 只会复读卡原文 / 接"费尔马大定理"胡扯 / 答"对"
- 改正: 复读"平凡零点在负偶数点上"×N / 胡扯"口音问题" / 反问"怎么改正"
→ 断层清晰: 无修正头
### LoRA (训练后)
- seen卡改正: **精准输出训练数据里的对句** (如"那些不落在平凡位置的零点，全躺在实部为二分之一的线上") ✅ 记住了
- unseen卡自发转述: 能自主组织句子, 但**概念错位**: "取零的路在实部大于1的段上,没有求零的工具"(错,应是实部>1无零点→说成有路/有工具)
  "ζ的适用范围被延拓到全实数域,用η函数一提就了"(错:η延拓到Re>0非全实数)
- unseen卡改正: 被教的"对照检查"套路上身, 但改出来的内容**数学上错**: "实部大于1的零点一串,没有的是非零的"、"全在实部小于0的半平面"(全错)
- 通病: 疯狂输出【END】占位符(训练标记泄漏), 生成被截断在第一个END, 每句短促

## 裁决结论 (关键)
1. **修正头能装上**(loss→0, seen卡逐字记住): 断层不是容量死刑, 是可训练的 ✅
2. **但装上的不是"去噪头", 是"复读头"**: 模型学到的是"改口段=背对句/背句式",
   没学到"读卡→对照→发现矛盾→改对"的**核对机制**
3. **泛化 = 概念错位 + 格式套用**: 它会"说人话"(自发组织句子)、会"走改正流程",
   但内容对错**毫无概念** — 因为它没有真核对(把卡和转述逐点比), 只是把"改口句式"背下来了
4. 【END】泄漏: 训练标记成了输出习惯 → 数据工程缺陷(去噪头不该教标记)

## 对"去噪头/扩散类比"的修正
- 扩散模型去噪是**像素级逐点对照**(每步知道"这格噪声该减多少")
- 我们教的 LoRA 是**句子级背答案** — 0.5B 没学会"逐点对照卡内容", 只会"整体换个说法"
- **真正的去噪头需要"对照单元"**: 把卡切成事实点(零点/实部/1/2), 每个点单独验证,
  而不是整句 paraphrase。 这需要 卡→事实点 的结构化数据(下一版方向)
- 但重大正面: 0.5B 在 22 对数据 120 步内就学会"读卡→自发组织→改正流程",
  说明"修正"这个**行为形态**可训练; 缺的是**逐点核对的内容粒度**, 不是行为本身
