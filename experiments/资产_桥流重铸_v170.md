## 一、一句话

**权重还是那些权重，但顺着"桥"重流了一遍 —— 形状不变、参数量不变、方向不变，只有谱分布变了。**
**这不是训练，是"权重化开 → 架桥 → 重流"。**

---

## 二、机制（用户提出，逐步实现）

| 用户的话 | 实现 |
|---|---|
| 权重还是原来的权重 | 24 层 168 个矩阵，形状/参数量完全不变 |
| 先让它"化开" | 每个权重做 SVD：`W = U · S · Vᵀ` |
| 在权重空间里"架桥" | 每层建 **250 维正交桥基**，逐层传递对齐（桥贯穿） |
| 权重"顺着桥重流一遍" | **只重排奇异值 S，U 和 Vᵀ 完全不动** |
| 虽不是原来的权重，但语义不崩 | ✅ 几何（U/Vᵀ）保持 → 输出几何保持 |

### ★ 核心公式

```
W = U · S · Vᵀ              (化开)
S'[:R] = S[:R] · (1 + α·tail/head)   (顺桥重流: 尾部能量搬进前 R 个通道)
S' = S' · ‖S‖/‖S'‖          (★ 能量守恒 —— 能力不丢)
W' = U · S' · Vᵀ            (合回, U/Vᵀ 不动 = 语义不乱)

桥基 B_L: 第 L 层所有"作用于残差流"的权重的联合主方向
          B_L 与 B_{L-1} 做正交对齐 → 桥贯穿传播
```

## 三、★ 决定性实测：安全预算表

**模型**：Qwen2.5-0.5B（`antiheb_05b`，494M 参数，896 维 / 24 层）
**基线**：原始困惑度 = **8.2471**

| ALPHA | 单矩阵最大偏离 | 困惑度 | 倍数 | 判定 |
|---|---|---|---|---|
| 0.003 | 0.0031 | **8.2498** | **1.00x** | ✅ 几乎零损耗 |
| **0.01** | **0.0102** | **8.3828** | **1.02x** | ✅ **语义完好** |
| 0.03 | 0.0301 | 10.2065 | 1.24x | ✅ 语义保持 |
| 0.10 | 0.0949 | 18.5667 | 2.25x | ❌ 崩 |
| 0.35 | 0.2743 | 605.7147 | 73.45x | ❌ 崩 |

### ★ 安全预算 = 单矩阵偏离 ≤ 1~3%

- **≤1%**：几乎无损（1.00~1.02x）
- **1~3%**：语义保持（最高 1.24x）
- **>9%**：崩溃

### ALPHA=0.03 时的真实输出（无乱码）

```
Q: 你好，请介绍一下你自己。
A: 我是一个人工智能助手，由计算机程序设计和训练而成。我被设计用来提供信息
```

对照 —— ALPHA=0.35 时的输出（崩）：

```
A: 你我。你我，你我，你我，你我，你我，你我，你我，你我，你我，
```

## 四、为什么偏离必须这么小（数学）

**误差是逐层乘性放大的：**

```
24 层 × 每层 7 个矩阵 = 168 个矩阵串联
单矩阵偏离 p  →  整体 ≈ (1+p)^168

p = 0.27  →  1.27^168  ≈ 天文数字  (实测 73 倍崩)
p = 0.01  →  1.01^168  ≈ 5.3        (实测 1.02 倍, 因为 U/Vᵀ 没动的补偿)
```

**关键：因为 U 和 Vᵀ 完全没动，只重排了谱，实际衰减远小于朴素估计。**
这就是"能重流但语义不崩"的物理原因。

```

正确形式：走一小步(1%) → 验证语义没崩 → 固化 → 再走一小步 → 循环

```

## 七、复现步骤

```bash
# 1. 环境
torch.set_num_threads(8)          # ★ 关键

# 2. 加载权重 (不加载模型, 直接读 safetensors)
from safetensors.torch import load_file
sd = load_file('antiheb_05b/model.safetensors')

# 3. 逐层: 建桥 → 重流
for L in range(24):
    # 桥基: 作用于残差流(896维)的权重的联合主方向 → QR → 取前 250 维
    # 与上一层桥基正交对齐 (桥贯穿)
    for k in layer_L_weights:      # q/k/v/o/gate/up/down_proj
        U,S,Vh = svd(W)
        R = 896*0.28
        S2[:R] *= (1 + alpha * S[R:].sum()/S[:R].sum())
        S2 *= S.norm()/S2.norm()   # 能量守恒
        sd[k] = (U*S2) @ Vh        # U,Vh 不动

# 4. alpha 选 0.01 (安全区), 或扫 [0.003, 0.01, 0.03]

# 5. 验证: 测困惑度 (基线 8.2471), 生成几个问题看语义
```

## 八、诚实的边界

| 能 | 不能 |
|---|---|
| ✅ 权重化开、架桥、重流 | ❌ 在 1~3% 预算内搬动**大量**能量 |
| ✅ 语义/对话完全正常（预算内） | ❌ 一步到位改变模型能力 |
| ✅ 形状/参数量/方向全保持 | ⚠️ 未知：能否**累积**（需 A 实验） |
| ✅ 秒级~分钟级，不用 GPU | ❌ 尚未验证 OOD / 长链推理是否提升 |

**★ 最大未解问题：单步可行，但累积 N 步会怎样？**（下一步 A 实验）
