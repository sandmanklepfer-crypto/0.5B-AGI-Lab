```
B 幅度控制 + 验证器: 总 43/45      ← 与"基线+验证器"完全相同!
```

**数学结构：**
```
基线        19

```

**验证器是凸包（superset），训练的收益是它的子集。**

## 四、★ 根因：这 9 个机制全在修同一个地方

```
种子     → 限制更新别偏离原点太远
影子     → 限制更新在低秩子空间
相位通道 → 限制更新别和历史重复
配额记忆 → 复用固定方向
anti-Heb → 限制更新别和已写方向重复
分层     → 调整各层步长
```

**它们全在做「约束权重更新的方向」。**

**而模型的病不在"更新方向"，在"它不会算"。**

**证据：**
```
S3 自持环: loss 0.0614  (几乎完全拟合训练集)  →  8/12
S2 影子:   loss 1.4180  (拟合差18倍)          →  8/12
```

**loss 差 23 倍，分数完全一样。**

> **修错地方的药，再精妙也是 8/12。**

## 五、分层机制的"用崩 vs 真没用"（V180 vs V181）

| 实现 | 方式 | 结果 |
|---|---|---|
| **D（V180，错）** | 分批**冻结**层，50步只更新138层次（B组400）→ 有效学习率 1/12 | **3/12** ❌ |
| **D1（V181，对）** | **每步全层更新**，只改步长分配 [1,2,4,8,16,32,64,128] | **9/12** ✅ |

**同一机制，3/12 vs 9/12，差别只在有没有"冻结"层。**

**诊断口径（可复用）：**
| 现象 | 含义 |
|---|---|
| `train_loss` 没降 | **机制用崩了** |
| `train_loss` 降了但分数跌 | 机制**学错了东西** |
| `train_loss` 降了分数也涨 | **机制真的有效** |

D 组 loss 只从 1.9720→1.8933（降 **4%**）→ 一眼看出没在训练。
D1 组 loss 降到 0.0481（降 **98%**）→ 才是真训练。

## 六、三层架构的最终结论

```
第1层 训练层（梯度 + 幅度控制 + 分层）
  贡献: 19→25 (+6 题, +13pt)
  但: 被验证器完全吞并 → 合体后边际贡献 = 0

第2层 推理层（形式库验证器）
  贡献: 19→43 (+24 题, +53pt)
  合体后独占全部收益

第3层 评测层（严格判分, 训练/泛化分离）
  绝不能进训练
```

### ★ 核心结论

> **推理层 >> 训练层。差距 4 倍（+24 vs +6），且推理层完全包含训练层。**
>
> **模型不会算，但验证器会。让验证器接管，比训练模型划算 4 倍。**
