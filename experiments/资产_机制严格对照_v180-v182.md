## 三、★ 三条硬结论

### ① 纯 SGD 有害，幅度控制有效

```
纯SGD:     6/12   (比不训练还差!)
幅度控制:  8/12   (loss 1.39 → 0.0768, 降 94%)
```

**同一个模型、同一批数据、同样 100 步，唯一差别是「patch 范数 = ‖W‖·scale」这个归一化。**
**这是 600 套里第一个被严格对照验证有效的训练层机制（V80/V81）。**

### ② "用崩了"和"真没用"必须分清 —— 分层机制的教训

```
D  分层(我冻结层, 50步只更新138层次)   →  3/12   ❌
D1 分层(每步全层更新, 只改步长分配)     →  9/12   ✅
```

**同一机制，3/12 vs 9/12，差别只在我有没有"冻结"层。**

**诊断口径（可复用）：**
| 现象 | 含义 |
|---|---|
| train_loss 没降 | **机制用崩了** |
| train_loss 降了但分数跌 | 机制**学错了东西** |
| train_loss 降了分数也涨 | **机制真的有效** |

**D 组 train_loss 只从 1.9720 → 1.8933（降 4%），一眼看出它没在训练。**
**D1 组 loss 降到 0.0481（降 98%），才是真训练。**

### ③ ★ 推理层 >> 训练层（最重要的一条）

```
所有训练层机制的努力:  7/12 → 最多 9/12   (+2)
仅加一个验证器:        7/12 → 12/12       (+5, 一步到位)
```

**验证器不需要训练、不需要 GPU、立刻满分。**

**E 组合体逐题明细（这才是"真会"）：**
```
数列              真值    模型答    采纳    结果
[1,2,5,14,42]     132     42      132     ✅
[2,7,20,57,166]   491     166     491     ✅
[1,3,6,10,15]      21     15      21      ✅
[1,8,27,64,125]   216     125     216     ✅
[5,10,20,40,80]   160     800     160     ✅
```
**模型答案几乎全错，验证器全部纠正对了。** 真会不在权重里。

## 四、⚠️ 诚实的边界（重要）

### ① 12 题的精度不够

```
12 题 → 1 题 = 8.3%
8/12 vs 9/12 = 只差 1 题 = 统计噪声
D1(深层猛)9 分, D2(浅层猛)9 分 — 方向完全相反, 同分
→ 说明"分层方向"可能不是关键, 差异在噪声范围内
```

**要真正分辨机制优劣，需要至少 50~100 题。**

### ② 任务是"数列"，不是通用能力

**所有结论只在这个题型上成立。** 换题型（方程/年龄问题）需重测。

### ③ "学习"的性质未定

```
目标集 loss 降 98%, 但 12 题里模型仍答错 4~5 题
→ 学到的可能是"格式", 不是"能力"
```

## 五、对用户原始问题的回答

> **"600 套合理配比上了吗？"**

| 事实 | 数据 |
|---|---|
| 之前从没上过 600 套 | ✅ 最多同屏 3 个 |
| 600 套不是"同一类调料" | ✅ 分 5 类，用途完全不同 |
| 配比思路本身错 | ✅ 是"工种分工"，不是"配方比例" |
| 训练层只有 1 个有效 | ✅ 幅度控制 |
| 推理层才是主力 | ✅ 验证器 12/12 |

**正确架构：**
```
第1层 训练: 梯度 + 幅度控制 (+ 分层, 边际)
      ↓
第2层 推理: 递归重生成 → 验证器 → 锚点 → 二分倒查   ← 主力在这
      ↓
第3层 评测: 严格判答案 / 活跃度 / 熵   ← 裁判, 绝不进训练
```

## 六、工程细节（避坑）

| 坑 | 现象 | 解法 |
|---|---|---|
| **冻结层做"分层"** | train_loss 不降, 分数暴跌 | ✅ **每步全层更新**, 只改步长分配 |
| 每步做 56 次 SVD | 慢 100 倍 | ✅ 参照系**预计算一次** |
| 磁盘 100% 满 | 模型存不下 | ⚠️ 用边训边测, 不存盘 |
| 竞态启动 | 两个实例同跑 | ✅ 先 pkill 再 launch, 且用 `'[_]name'` 防自匹配 |
| `labels` 含 pad | 基线 ppl 虚高到 121 | ✅ `labels[A==0] = -100` |
| `optimizer` 传 module | TypeError | ✅ 传 `.weight` |

## 八、一句话

> **第一次把 600 套拆成三层、用严格判分对照跑了一遍。**
