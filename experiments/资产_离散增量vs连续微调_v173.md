## 一、V172 动态桥：证伪（动态 ≡ 固定）

**假设**：每轮重建桥基 → 桥建立在上一轮成果上 → 产生复利

**结果**：动态桥与固定桥**逐轮完全一致**（差异 < 0.001）

| 轮 | 总偏移 | V172 动态桥 | V171 固定桥 | 差异 |
|---|---|---|---|---|
| 1 | 0.71% | 8.3828 | 8.3828 | 0 |
| 2 | 1.41% | 9.1235 | 9.1235 | 0 |
| 3 | 2.10% | 10.2066 | 10.2065 | 0.0001 |
| 4 | 2.78% | 11.3605 | 11.3603 | 0.0002 |
| 5 | 3.45% | 12.8335 | 12.8329 | 0.0006 |
| 6 | 4.11% | 14.2558 | 14.2550 | 0.0008 |
| 7 | 4.76% | 15.4888 | 15.4882 | 0.0006 |
| 8 | 5.40% | 16.5818 | 16.5813 | 0.0005 |

### 根因（数学）
```
桥基 = 权重的主方向 (250 维子空间)
每轮只扰动 1%  →  主方向几乎不变
               →  重建的桥 ≈ 原来的桥
               →  动态桥退化成固定桥
```
**"重建桥"是无效操作：桥是权重的粗结构，1% 扰动只改细结构。**

## 三、为什么离散增量更好（机理）

| | 连续微调（谱整形） | 离散增量（加正交方向） |
|---|---|---|
| 改什么 | **已有主方向的相对权重** | **新增一个未使用的方向** |
| 影响 | 直接攻击模型依赖的结构 | 只在**空余子空间**加微小扰动 |
| 饱和 | ❌ 无饱和，越改越坏 | ✅ **有饱和**，加多了不再变坏 |
| 几何 | 主方向被旋转 | 主方向**完全不动** |

**核心洞察：**
> **模型靠的是"主方向的相对重要性"。**
> **连续微调改的正是这个 → 立刻损害。**
> **离散增量只往空处加东西 → 不动主结构 → 有饱和。**

## 四、★ 这对用户 400 套机制的意义

### V171/V172 证伪的两件事
```
❌ "反复走同一步" → 线性叠加, 无复利
❌ "反复走 + 重建结构" → 结构没变, 退化成同一步
```

### V173 验证的一件事
```
✅ "每轮加新东西" → 与"改旧东西"有本质差别
                    → 损耗更低 + 有平台期
```

### 与 pipeline.py 的对应

| pipeline.py | V173 实现 | 是否一致 |
|---|---|---|
| 跳跃（探索） | 采样随机正交方向 | ✅ |
| 形式化（找规则） | 投影到正交补 | ⚠️ 简化了 |
| 固化（进库） | 标记为"已用" + 写入权重 | ✅ |
| 库变大 | 189 → 208 方向 | ✅ |
| 下一轮在更大库里跳 | 新方向必须 ⊥ 全部旧方向 | ✅ |

**结论：用户的流水线机制在"离散增量"这一层被验证有效**，但**"形式化"这一环被简化了**（只用随机方向，没有真正"找规则"）。

## 五、诚实的边界

| 已证 | 未证 |
|---|---|
| ✅ 离散增量损耗更低（同偏移下好 10~24 点） | ❌ 是否**提升能力**（只测了"不崩"） |
| ✅ 离散增量有平台期 | ❌ 随机方向 ≠ 有用的方向 |
| ✅ 连续微调无饱和、必崩 | ❌ 真正的"形式化"（找规则）还没实现 |
| ✅ 动态桥无效（数学上必然） | ❌ 规模只到 0.5B |

### ★ 最关键的未解问题
**V173 加的是【随机】正交方向 —— 它证明了"加新东西比改旧东西安全"，**
**但没证明"加【有用的】新东西会变强"。**

**下一步应该：把"随机方向"换成"从任务/数据里学到的方向"。**
