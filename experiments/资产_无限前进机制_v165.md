## 二、★ 硬界限: 可逆 ⇒ 无判别力 (热力学第二定律)
```
纯正交:    往返误差 1e-15, 正常/异常输入完全一样 → 零判别
猫映射:    可逆, 但结构 1 步内混合 (分离比 1.051→0.995) → 零判别
纯收敛:    有判别, 但塌缩成一点 → 退化

结论: 可逆 = 信息守恒 = 不产生判别 (物理必然, 非算法问题)
```

## 三、★ 决定性实验: 世界变化速度 → 新发现数量
```
漂移速度    新发现数    判定
0.00       1         ❌ 饱和 (固定世界必然收敛)
0.05       1         ❌ 饱和
0.10       0         ❌ 饱和
0.20       1         ❌ 饱和
0.35       4         ✓ 持续

0.80       4         ✓ 持续

→ U 形曲线! 太快和太慢都不行, 中间最优
```

## 四、★ "无限前进"的三条件 (缺一不可)
```
① 可逆探索      → 提供无穷候选  (保面积映射/相位通道)  ✅ 已有
② 退火收敛      → 提供方向      (切空间写活)          ✅ 已有
③ 世界持续变化   → 提供新目标    (速度必须匹配)        ❌ 关键缺口

数学必然: 固定景观的退火 = 单调降能 = 必然停在全局最优 = 结束
```

## 七、副产品: SVD 点云 vs 二元对错
```
反馈方式          准确率
二元对错 (1 bit)   0.7133
★SVD坐标 (K值)     0.7500  (+5.1%)
K=8 时优势更大 (+6%)

机制: 二元只传 1 bit; SVD坐标传 K 个连续值
      = 系统自己从粗反馈里榨出几何信息
```

## 八、保面积映射的性质 (可作时间通道)
```

  可逆:            理论完全可逆 (整数矩阵)

用途: 比相位更强的"时间通道"; 强混合特性可作"遗忘机制"
```
