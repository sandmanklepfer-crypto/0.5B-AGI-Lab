# 正式资产: 三闭环检验 V162 — 结论: 不是更强
## 状态: ✅ 已验证 (本地纯 numpy, 秒级) | 承 V161

## 一、被检验的假设
用户假设: 加入「形式语言与自动机 / 符号动力学」作为第三个库,
把「混沌系统」和「基础算术」串起来形成闭环 → 更强, 且权衡自然出现。

## 二、★ 决定性结果: 三闭环更弱

### 测试1: 极端外推 (训练 (a,0)/(0,b) 9种 → 测试 (a,b) 16种)
| 方式 | a恢复 | b恢复 | 外推 |
|---|---|---|---|
| ①连续读出 | 1.000 | 1.000 | **1.000** |
| ②符号K=5 | 0.000 | 0.750 | 0.062 |
| ②符号K=10 | 0.000 | 0.938 | 0.000 |
| ②符号K=36 | 0.000 | 0.938 | 0.000 |

### 测试2: 公平外推 (随机15种训练 → 10种全新组合)
| 方式 | a恢复 | b恢复 | 外推 |
|---|---|---|---|
| ①连续读出 | 1.000 | 1.000 | **1.000** |
| ②符号K=10 | 0.000 | 1.000 | 0.000 |
| ②符号K=20 | 0.000 | 0.900 | 0.100 |
| ②符号K=40 | 0.000 | 0.900 | 0.100 |

**两次测试, 符号划分的外推都崩溃。结论: 三闭环(含符号动力学)不是更强, 而是更弱。**

## 三、★ 根因: 离散化吃掉「弱信号」

关键线索: `a=0.000` 但 `b=0.900`。
- a 是**先**注入的符号 (t=0-10), 在末状态里是**弱分量**
- b 是**后**注入的符号 (t=10-20), 在末状态里是**强分量**

```
连续读出: 状态 ≈ f(a) + f(b)  (线性叠加)
          → 线性映射能同时放大并分离 强/弱 两个分量 → a,b 都恢复

符号划分: 符号 = 最近中心
          → 中心由「强分量」主导 → 符号只编码了 b
          → a 的信息在离散化时被吞掉
```

**离散化 = 有损压缩到最近的中心 = 弱信号被强信号淹没。**

## 四、理论含义 (重要)

| | 连续表示 | 离散表示 |
|---|---|---|
| 组合外推 | ✅ 能 (叠加结构保持) | ❌ 不能 (边界封闭) |
| 精确操作 | ⚠️ 模糊 | ✅ 精确 |
| 可检查 | ❌ | ✅ |

**"离散化必须预先定义边界, 而预先定义 = 必须见过"。**
→ 离散边界无法外推到训练分布之外。

## 五、★ 正确的架构: 离散化放在「输出端」, 不在「表示端」

```
❌ 错 (三闭环):  脑 → 离散符号 → 形式运算 → 输出
                   ↑ 这里丢信息, 弱信号被吃掉

✅ 对 (两库):    脑 → 连续读出 → 数值 a,b → 外部形式运算 → 输出
                   ↑ 保持叠加结构      ↑ 精确操作在这里
```

**关键原则: 运算在数值域, 离散化只在最后输出。**
这与计算机一致: CPU 内部用二进制做加法, 但"读出"保持精度。

## 六、因此 (修正 V161)
**V161 的架构是正确的, 不需要加符号动力学环节。**
- 连续读出: 保持叠加结构, 外推 1.000
- 外部形式系统: 提供精确运算
- 两者分工, 各司其职

**"符号动力学"作为诊断工具仍有价值** (D2/RR/H 判定生死, V161 已验证),
**但作为「表示层」会损害能力。**

## 七、对"权衡自然出现"的检验
用户认为: 加了三闭环, 注意力权衡会自然出现, 不用手动加。
检验: 划分粒度 K 确实产生权衡 (K小→装不下历史; K大→噪声主导)。
**但代价是外推能力归零 —— 这个权衡的"价格"太高, 不值得买。**
