## 二、设计：16 原语 + 5 组合器，0 条手写规则

```
原语(16): 1, n, n², n³, 2ⁿ, 3ⁿ, n!, fib, prime, tri, sqsum,
          catalan, C(2n,n), 2n-1, (-1)ⁿ, n·(-1)ⁿ

组合器(5):
  ① 线性组合   a·f₁ + b·f₂         (系数扫描)
  ② 乘积       f₁·f₂, f·f, f₁²·f₂
  ③ 前缀和     Σf  ← 差分的逆 (★关键)
  ④ 平移       f(k+d)              (起点偏移)
  ⑤ 递推       a(k+1) = p·a(k) + q·k + r   (解3元一次)
```

**★ 关键洞察：指数覆盖不来自暴力枚举，来自【差分降阶】**
```
若 Δa 匹配某形式 → a = 前缀和(那个形式)
若 a 满足递推 → 3个参数(p,q,r) × 3个原语 = 无穷多序列
```
