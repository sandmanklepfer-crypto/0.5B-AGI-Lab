## 三、★ 一个重要教训：测试题本身会出错

**最初判定的 2 个"失败"，全部是我自己算错真值：**

```
prime+k:      我以为 [3,5,8,11,16] → 23
              实际 → 19  (素数2,3,5,7,11,13 + k=1..6)
              引擎给出 1*n+1*prime → 19  ✅ 引擎对, 我错

n²·(−1)ⁿ:     我写的序列符号从正开始
              引擎给出 n*n*(-1)^n → 36  ✅ 引擎对, 我错
```

**这说明一件重要的事：**
```
一个【不会乱猜】的引擎, 在出题人犯错时会显得"错"
—— 因为它给的是正确答案, 而出题人期望错答案

而模型(L183)会跟着出题人的错走 —— 因为它在迎合, 不在计算
```

**这是"计算"和"迎合"最干净的区分实验。**
