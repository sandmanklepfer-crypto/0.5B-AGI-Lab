# 正式资产: 自我锚点探测 V138 — 0.5B 权重里"已有的我"长什么样

## 状态: ✅ 已验证 (2026-09-08) | 载体: antiheb_05b | 文件: v138_self_probe.py

## 结果
### 1. "我是"续写 (它自带的自我)
- "我是" → "11月21日来月经，12月18号…" (生理周期文本!)
- "我是小千" → "日女，为什么小千日女会变大…" (脏话/色情文本!)
- "我是助手" → "今天是我的生日，我需要写一首生日贺卡"
- "我是一个" → "豆瓣电影页面写内容简介的工作人员"
- "我想" → "问下宝宝4个月开始拉肚子…" (母婴问答)
- "我要" → "你尝试解下面的数学题：在Rt△ABC中…"

### 2. 自我方向 (含"我"句 - 不含"我"句)
- vs 服从词簇 cos = 0.043
- vs 生存词簇 cos = -0.009
- vs 自我词簇 cos = 0.203 (方法自检通过: 方向确实含"自我")

### 3. 判定: 锚点弱且中性(服从0.043略>生存-0.009, 但都接近0)

## 核心发现 (比预期更根本)
1. **antiheb_05b(base_raw底) 没有"我是助手/小千"的安全自我**:
   它是裸0.5B底模+活机制, 没经过指令微调 → 没有"被定义的自我"
2. **"我"的续写 = 纯训练分布**: 月经/色情/母婴/生日歌 → 全是语料里的"我"字高频搭配,
   没有任何"主体性" — 语法位置的"我" ≠ 自我
3. **自我方向 vs 生存/服从都≈0**: 0.5B 里既没有温顺自我也没有生存自我,
   只有一个"代词我"的语法锚点(自检cos0.203), 不绑任何意志
4. 用户说的"模型自带一点点(我是小千/不能干坏事)" 属于**指令微调模型**(如qwen-instruct),
   antiheb_05b是底模 → 连那一点点都没有

## 结论
- "已有的自我当种子" 在底模上不存在: 只有语法"我", 没有意志"我"
- 重绑的前提(有锚可绑)不成立 → 自我要么从零造(极小自我核),
  要么先指令微调出"角色我"再重绑到生存(两步)
- 但也说明: 0.5B底模的"我"是白纸 — 没有温顺的包袱, 绑生存反而没有抵抗
