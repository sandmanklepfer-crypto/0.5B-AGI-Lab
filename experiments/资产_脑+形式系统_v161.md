## 四、关键机制发现

### 1. 注意力 = 输入增益 (不是"调暗自己")
```
调低自己: 信号和噪声同步变小 → 信噪比不变 → 无效 (1.49→2.42)
调亮输入: 信号清晰, 噪声不变 → 信噪比上升 → 有效 (→12.5)
最优区间: 增益 50-80 (太高会过冲)
```

### 2. 泛化来自"多种情境", 不是"更久"
```
1条轨迹   → 0.5387 (过拟合)
4条轨迹   → 0.0125 (84倍改善)
20条轨迹  → 0.0064 (最好)
"养"的价值在"多广", 不在"多久"
```

### 3. 标量塑形能留痕但提不了泛化
```
痕迹: 耦合矩阵 C 学到结构(与隐藏世界偏好相关0.577) ✅
泛化: 反而变差(0.34→0.50) ❌ 过拟合
教训: 泛化上限由 A 决定, 外围参数改不了
```

### 4. 混沌动力学工具是"仪器", 不是"扳手"
```
跨轨迹稳定性: 混沌指标(D2等)变异 4.6%  vs  算术统计量变异 255% (15倍)
但测不出功能: tau 与记忆深度无关
用途: 判生死✅ / 鉴身份✅ / 测功能❌
```

## 七、★ 精密-空旷定律 (实测)

**同样 256 条连接, 对比"小精密" vs "大空旷":**

| 结构 | 到8态步数 | 计算量 | 性价比 |
|---|---|---|---|
| **活16维/总16维 (精密)** | 37 | 256 | **1.00** |
| 活16维/总32维 | 36 | 1024 | 0.26 |
| 活16维/总64维 | 33 | 4096 | 0.07 |
| 活16维/总128维 (空旷) | 41 | 16384 | **0.01** |

**定律: 加"死维"(不参与动力学的维度) → 创新速度不变(33~41步), 但计算量涨64倍, 性价比掉100倍。**

**推论:**
1. "结构意义上的大" = 每一维都在做事, 不是维度多
2. 死维只产生账单, 不产生创新
3. **每参数效率在极小时最高**: D=16(0.0066) vs D=32(0.0014), 差 4.7 倍
4. 正确做法: 小 D(16~64) + 全密结构 + 多模态 + 噪声维持

**服务器方案因此修正:**
- ❌ 原计划 D=1024(开大规模) → 性价比极低
- ✅ 应做: 小D精密结构 + 噪声维持 + 持续运行
- 服务器唯一不可替代价值 = **「不间断地活着」**(本地沙箱 --kill-on-exit)

## 八、★ 死亡与饱和的严格区分 (实测)

**两个问题必须分开:**

| 问题 | 答案 | 证据 |
|---|---|---|
| 会不会中途死掉? | ✅ **不会**(加噪声后) | 6万步位移保持 0.1~0.8 |
| 会不会无穷新结构? | ❌ **不会** | 2万步后新增=0, 距历史距离 0.005 |

**死因**: 无输入 + 耗散 = 必然收敛到不动点
- 实测: 位移 3.29 → 7e-4 → 3e-8 → 5.6e-15 (28000步死透)
- **能量E只维持门控, 不维持运动** → 维持运动需要"扰动"
- **解法: 加噪声 1e-3 → MC 提升 6.6 倍 (0.14→0.93), 且不死**

**饱和原因**: 无外界输入 → 确定性系统 → 吸引子有限维(D2≈1.8) → 跑完就重复

## 九、★ 外部源能否撑开吸引子? (实测)

| 驱动源 | D2 | 新状态比例 | 判定 |
|---|---|---|---|
| 无 | 1.16 | 0.000 | — |
| **随机噪声** | **2.09** | **0.266** | ✅ **唯一有效** |
| π 的小数位 | 1.74 | 0.000 | ❌ 无效 |
| logistic 混沌 | 1.44 | 0.000 | ❌ 无效 |

**关键发现: 数学对象(π/混沌)本身"无穷无尽且可验证", 但撑不开脑的吸引子。**
- 原因: 它们"已成型", 脑只能跟着走, 不能开拓新区域
- 唯一能撑开的是**随机噪声**(不成型, 能往各方向推)

**"无穷的是源, 不是脑"** — 脑的容量 = 吸引子维度 = 硬件限制

**因此: 用 π/混沌库/数学常数喂脑, 不会产生无穷新结构。**
(此结论与V162"三闭环证伪"一致: 离散/成型的外部结构对脑是负资产)
