## 三、tanh vs 相位 (关键区别)
```
tanh(累积幅度)    → 收敛到1, 位移 5.6e-15  = 死
cos(无理频率累积)  → 永不精确重复          = 生

数学定理: 若 ω/2π 无理, 则 {cos(nω)} 永不精确重复
  证明: 若重复 → nω-mω=2πk → ω/2π=k/(n-m) 有理, 矛盾
```

## 四、★ 最终方案: 双通道正交
```
幅度通道 = 正交核 A + tanh      → 内容、语义 (有界)
相位通道 = Kuramoto 振荡器       → 时间、顺序 (无界)
两者【只读组合】, 相位不驱动幅度
```

**Kuramoto**: φ_{t+1} = φ_t + DT·(ω_i + K/N·Σ sin(φ_j−φ_i))
- ω 取无理频率比 (1.0, 1.618, 2.414, 1.732, 2.236, ...)
- 相位无界累积 → 永不重复
- sin 耦合有界 → 不爆炸
