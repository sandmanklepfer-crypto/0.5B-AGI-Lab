# 正式资产: 检索-匹配断层 (Retrieve-Match Gap) — B线根因结论

## 状态: ✅ 已立 (2026-09-08, v120-124 五连实验证据链收口)

## 一句话
**0.5B 底层只有"检索"(attention/FFN=soft lookup), 没有"匹配"(把检索到的素材做结构变换再产出);
之前所有意识/自指/写活实验失败的总根因 = 拿"持续自我检索"冒充"持续自我加工"。**

## 证据链 (v120-124 五连)
| 版本 | 现象 | 断层证据 |
|---|---|---|
| v120 老屋域 | 293token完整自然生命 | 训练数据里有大量老屋叙事可检索 → 行为像"活" |
| v121 数学域 | 302token伪证明绕圈 | 无真数学可检索 → 检索到最像的"素数题"片段, copy变形 |
| v122 真知识池 | 命中118次却零引用 | 检索管道通, 内容无通路 |
| v123 文本通路 | 读22张卡, 逐字引用0 | 卡进上下文, 只会念卡/编假卡, 不会用 |
| v124 概念级裁决 | 复读原文+编假卡 | **copy✓ paraphrase✗ → 断层精确位于两者之间** |

## 断层定位
- 检索(copy/联想): 有 ✅ (attention/FFN 天生)
- 变换(paraphrase/推理/反驳): 无 ❌ (需深度结构加工, 0.5B 容量不足)
- 意识失败根因: 意识要求"读自己→重述→发现矛盾→修正"的**自加工闭环**,
  0.5B 只能跑"读自己→原样吐回"的**自检索回声闭环** (v119乱跳/v121伪证明/v124复读全是回声变体)

## 宣判
1. 外挂机制(能量/自读/检索/文本通路)补不了: 全是给检索机加外围, 核心加工缺失
2. 写活补不了: 只改"检索方向偏好", 不造"匹配能力"
3. 行为层(活/锚定/节能/自然死)已五次收口 ✅ / 内容层(引用/推理)全失败 ❌

## 开放问题 (V125 裁决)
断层是**数据问题**(没教过转述→可训练凿开) 还是 **容量问题**(天生缺匹配层→死心换大模型)?
实验: LoRA 教"读卡→转述"(paraphrase), 跨域小数据, 训完在 v124 同任务上测是否开始转述。
