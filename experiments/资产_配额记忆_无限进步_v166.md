## 一、★ 修正 V165 的结论
V165 说"无限进步不成立"——**那个结论太宽了, 必须修正。**

| 方案 | 结果 | 原因 |
|---|---|---|
| 权重写活 (内化) | ❌ 每步 -5%, 净收益趋零 | 写权重有损, 新旧互相覆盖 |
| **外挂配额记忆** | ✅ **0.995~0.959** | 存储无损, 不遗忘 |

**关键区别: 动不动权重。**
- 动权重 → 灾难性遗忘 → 不能持续进步
- 不动权重 → 无损保留 → 持续进步

## 四、诚实: 不是"完全解决"
```
① 缓慢衰减: 0.995 → 0.959 (类别 20→60)
② 需要类别信息 (真实世界需聚类代替标签)
③ 容量仍随类别数增长 O(N类), 非 O(1) — 但系数小(0.68)
```

## 五、为什么外挂配额能成立而权重内化不能
```
外挂配额: 存储无损 → 旧样本原样保留 → 无遗忘
          检索无损 → 直接查最近邻   → 无失真
权重内化: 写权重有损(-5%/步) → 新旧覆盖 → 灾难性遗忘

→ 正解: 记住经历, 不要内化经历
→ 这正是 V120「知识=环境(需主动检索)」的原话
```
