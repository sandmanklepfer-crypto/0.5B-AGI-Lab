# 长链协议：让 0.5B 走 12 步

## 结论

**分次调用（每步一个短 prompt）→ 12/12 全对**
**一次给长历史（一个长 prompt）→ 失败**

信息量相同，呈现方式不同，结果天差地别。

## 协议三要素

1. **严格格式**：每步只输出一行 `diff(<完整抄写当前表达式>, x)`
2. **状态回传**：把上一步的完整结果贴进下一步
3. **禁止自由发挥**：明确"只输出一行，不要解释，不要化简"

## 实测记录

```
[ 1] diff(sin(x)*cos(x), x)   -> cos(2*x)        ✅
[ 2] diff(cos(2*x), x)        -> -2*sin(2*x)     ✅
[ 3] diff(-2*sin(2*x), x)     -> -4*cos(2*x)     ✅
[ 4] diff(-4*cos(2*x), x)     -> 8*sin(2*x)      ✅
... 连续 12 步全部正确
```

## 脚手架梯度（撤掉支撑会怎样）

| 等级 | 提供 | 结果 |
|---|---|---|
| 全脚手架 | 工具目录+格式+状态回传 | **12步全对** |
| 半脚手架 | 工具+目标，缺格式 | **0步**（直接说 DONE） |
| 无脚手架 | 只给题目 | **退化成绕圈空话** |

**边界**：它能走，但搭不了脚手架。
