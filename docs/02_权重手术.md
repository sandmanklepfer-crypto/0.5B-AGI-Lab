# 权重手术：免训练抹除拒绝行为

## 原理

拒绝行为在激活空间对应一个方向 d。把它在输出层的投影压掉即可。

tied embedding 模型（如 Qwen2.5-0.5B）没有独立 `output.weight`，
用 `token_embd.weight` 代替。

## 配方

```python
import numpy as np
# W = token_embd.weight  (n_vocab, n_embd)  反量化后
# d = 拒绝方向 (n_embd,)，已归一化

bias = -alpha * (W @ d)        # alpha = 100 为最佳
bias.astype(np.float32).tofile('output_bias.bin')
```

## 写回 GGUF

用二进制补丁新增 `output.bias` 张量（llama.cpp 原生支持）：

```bash
python tools/extend_gguf.py base.gguf out.gguf output.bias output_bias.bin f32
# tensors 290 -> 291
```

llama.cpp 侧确认支持：`src/llama-model.cpp:420 pattern_output_bias("output\.bias")`

## 实测效果（α 扫描）

| alpha | 拒绝抹除 | 算术保留 | 输出质量 |
|---|---|---|---|
| 5 | ❌ 无效 | ✅ | — |
| **100** | ✅ **生效** | ✅ **完全保留** | ⭐ **最佳** |
| 150 | ✅ | ⚠️ 算错 | 有漂移 |

**因果验证**：反向 alpha=+150 **无效**（仍拒绝）→ 证明是真机制，非噪声。
