# 形式库：真正的瓶颈

## 发现

同一数列，同一个搜索器，只多给一种"形式"，就命中了：

```
数列 [2, 7, 20, 57, 166]

只有"封闭公式"形式  → ❌ 搜不到
加上"递归形式"      → ✅ 命中 a_n = 3·a_(n-1) − 2n + 5
                        预测 [491, 1464]  完全正确
```

## 形式清单

| 形式 | 状态 | 例子 |
|---|---|---|
| 封闭公式（多项式/指数） | ✅ 现有 | `n²`, `2ⁿ` |
| 递归/差分方程 | ✅ 已验证有效 | `3a_(n-1)−2n+5` |

## 自举能力实测

能从数据反推**原子**：
```
数列比值 [3.5, 2.86, 2.85, 2.91] → 接近3
对数拟合 base = 2.985  →  猜底数 3  ✅ 自动识出
```

但**造不出新形式**（需要人来加）。

## 对比：模型 vs 搜索器

| 题 | 搜索器+验证器 | 模型 |
|---|---|---|
| `[1,4,9,16,25]` | ✅ `n^2` | ❌ "前两项之和" |
| `[3,8,15,24,35]` | ✅ `2n+n²` | ❌ "前一项减1" |
| `[2,4,8,16,32]` | ✅ `2^n` | ❌ "前两项之和" |
| `[1,2,5,14,42]` | ✅ `catalan` | ❌ "前两项之和" |

**模型 0/5，且5次都用同一个模板（"前两项之和"）。**
**搜索器+精确验证器：4/5。**
