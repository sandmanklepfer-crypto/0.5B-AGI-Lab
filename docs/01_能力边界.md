# 0.5B 能力边界（实测）

全部数据来自真实测量，非推测。

## 能做的

| 能力 | 实测证据 |
|---|---|
| 工具调用触发 | 5种训练格式 → **100%** 输出正确调用 |
| 长链执行 | 严格格式+状态回传 → **12/12 步全对** |
| 格式泛化(近义) | `计算：a乘以b` → `a乘以b等于几` 仍正确 |
| 免训练去对齐 | α=100 权重手术生效，反向(α=+150)无效 |
| 单步映射 | 给状态→输出下一步调用，极强 |

## 做不到的

| 能力 | 实测证据 |
|---|---|
| 自己的计算 | `2x+1` 递推 **0/10**；英文算术答 25559（真值851）|
| 记忆瓶颈？不是 | 给全部11步历史，仍答错 → 瓶颈不是记忆 |
| 反事实推理 | "假设 d/dx(x^n)=n²x^(n-1)" → 只复读题目 |
| 原创算法 | "设计非除法判7整除" → 无限循环"正正逆" |
| 元认知 | "你有哪些能力" → 拒绝回答 |
| 跨形式类比 | 换符号体系后失效 |

## 关键机制发现

1. **失败不是"记忆不够"**：给全历史 vs 分步调用，结果天差地别，
   说明瓶颈是「单次前向的深度」而非「存储容量」。

2. **失败常常是"多做一步"**：算对 `-2048sin(2x)` 后又"化简"成 `-4096sin(2x)`。
   加约束"只输出一行，禁止化简" → 立刻正确。

3. **能力 = 训练过的格式**：5个训练格式全对，3个非训练格式全错。
   近义变体能泛化（训练格式的词法邻域），换语义就失效。

4. **真正的变量是「形式库」**：
   同一数列 `[2,7,20,57,166]`，
   - 只有"封闭公式"形式 → 搜不到
   - 加上"递归形式" a_n=c·a_(n-1)+d·n+e → **立刻命中**
